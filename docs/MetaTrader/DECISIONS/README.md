# Architecture Decision Records (ADR)

Esta carpeta contiene decisiones arquitectónicas **importantes** que deben quedar congeladas: aquellas que, si se revirtieran, obligarían a rehacer trabajo significativo o afectarían a la seguridad del sistema.

No se crea un ADR por cada elección menor. Se crea uno cuando una investigación produce una decisión que:

- afecta a más de un documento o componente,
- es costosa de revertir,
- tiene implicaciones de seguridad o de manejo de dinero (aunque sea demo),
- fue objeto de una alternativa seria descartada con razones concretas.

## Formato

```markdown
# ADR-NNN — Título

**Fecha:** AAAA-MM-DD
**Estado:** Propuesta | Aceptada | Reemplazada por ADR-XXX

## Contexto
## Decisión
## Alternativas consideradas
## Consecuencias
```
