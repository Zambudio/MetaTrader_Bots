# MetaTrader_Bots
Configuracion multiagente para estrategias y bots en Metatrader 5

## Contenido de este repositorio

- [`docs/MetaTrader/`](docs/MetaTrader/00_INDEX.md) — investigación y documentación técnica previa a la puesta en marcha (arquitectura MT5, MQL5, backtesting, riesgo, despliegue, etc.). Ver también `Promp_InicioMetaTrader_Investigar.md`, el prompt maestro que guio esa investigación.
- [`trading-agents-dashboard/`](trading-agents-dashboard/README.md) — consola web de agentes de IA para análisis y propuesta de estrategia (indicadores, entrada, stop loss, take profit). Es una herramienta de investigación, no de ejecución: el resultado se usa manualmente para configurar Expert Advisors en MetaTrader.
- [`wiki/`](wiki/index.md) — wiki de conocimiento de trading (velas, indicadores, estrategias, análisis fundamental, gestión de riesgo), mantenida por Claude Code siguiendo el patrón [LLM Wiki de Karpathy](wiki/METHODOLOGY.md). Fuente de referencia de propósito general, separada de la investigación de ingeniería de `docs/MetaTrader/`.
